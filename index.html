💡 Συχνές Ερωτήσεις (FAQ)
Πώς μπορώ να μπω στην ομάδα ή να γίνω developer; +
Μπορείς να επικοινωνήσεις μαζί μας μέσω του επίσημου Discord server μας για να μάθεις πότε ανοίγουν αιτήσεις για τηστείλετε τα δείγματα δουλειάς σας.
Αντιμετωπίζω bug σε κάποιο παιχνίδι. Πού το αναφέρω; +
Μπορείς να συμπληρώσεις την παρακάτω φόρμα υποστήριξης ή να ανοίξεις ticket στο Discord κανάλι μας περιγράφοντας το πρόβλημα.
Πότε θα βγουν νέα updates στα παιχνίδια; +
Όλα τα νέα announcements και τα patch notes ανακοινώνονται πρώτα στο Discord και στο YouTube κανάλι μας!
