Μπορείς να επικοινωνήσεις μαζί μας μέσω του επίσημου Discord server μας για να μάθεις πότε ανοίγουν αιτήσεις.
Αντιμετωπίζω bug σε κάποιο παιχνίδι. Πού το αναφέρω; +
Μπορείς να συμπληρώσεις την παρακάτω φόρμα υποστήριξης ή να ανοίξεις ticket στο Discord κανάλι μας.
Χρησιμοποιεί η ιστοσελίδα cookies; +
Χρησιμοποιούμε μόνο βασικά και απαραίτητα cookies (τοπική αποθήκευση LocalStorage) για να αποθηκεύουμε τις προτιμήσεις σου, όπως το επιλεγμένο θέμα εμφάνισης (Theme) και τις ρυθμίσεις ήχου. Δεν συλλέγουμε ούτε κοινοποιούμε προσωπικά δεδομένα.
Πότε θα βγουν νέα updates στα παιχνίδια; +
Όλα τα νέα announcements και τα patch notes ανακοινώνονται πρώτα στο Discord και στο YouTube κανάλι μας!
